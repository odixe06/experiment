# SR-LiCNN source availability

Luo, Wang, Li and Luo, Computers & Security 151, 104304, April 2025. [Publisher](https://doi.org/10.1016/j.cose.2024.104304).

The accessible publisher abstract describes spectral-residual preprocessing, image construction from in-vehicle signal sequences, and a customized depthwise-separable CNN. Evaluation uses SynCAN and ROAD.

The full PDF and authors' implementation have not been obtained. Exact layer configuration, image construction and parameter count remain unverified. The previously quoted 111,786 comes from a later paper's literature table.
